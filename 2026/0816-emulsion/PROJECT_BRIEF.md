# PROJECT_BRIEF — 0816-emulsion

## 一言

**乳剤。暗室の重ね焼き。** 2D の版と 3D の被写体を別々の感光層に焼き、`MergePass` で
1 枚の印画紙に重ねる。焼き方を変えると、同じ 2 層がまったく別の写真になる。

## 意図

「2D と 3D が混在する」を、**同じフレームに混ぜる**のではなく
**別々に焼いてから重ねる**方向で扱う。

- 2D の版 (`Graphics`) — 等高線と網点の銅版画。青緑の単色に寄せる
- 3D の被写体 (`Graphics3D`) — 球と 3 枚の環と衛星でできた構成体。琥珀色。ゆっくり回る
- 講評欄 (`Graphics`) — 判定と説明。**これも層として焼く**（グラフを立てると
  メインキャンバスの描画は画面に出ないため）

暗室の作法をそのまま構成にする。最初に**露光テスト（テストストリップ）**を焼いて、
装置が正しいかを確かめてから本焼きに入る。

## 場面

| | 場面 | 見せるもの |
|---|---|---|
| 1 | 版下 Plate | グラフを外し、2 枚の層を左右に並べる |
| 2 | 重ね焼き Superimpose | 同じ 2 層を `.screen` → `.add` → `.multiply` → `.alpha` で焼き直す |
| 3 | 分岐 Branch | 版が 2 経路へ分かれ、片方だけ `InvertEffect` を通る。版 × 版のネガ |
| 4 | 交錯 Seam | グラフを外し、1 フレームに 2D と 3D を混ぜる |

1 場面 15 秒、1 巡 60 秒。

## 想定どおりと言える条件

- `tools/probe.sh twice` が、2 回続けて**完全に同じ判定行**を出す（決定論）
- FAIL の行に期待値と実測値が数値で並んでいる
- 4 場面を巡回して単体で見ていられる絵になっている

## 検証としての狙い

`MetaphorRenderGraph`（8 API すべて未使用）と `createGraphics3D`（実際に描いた例が無い）を
通す。同じ 2 層を **3 通りの定規**で重ねて突き合わせる:

1. `MergePass` — GPU のパス合成
2. doc の式を CPU で計算 — 層を `toImage().loadPixels()` で読み戻す
3. `image()` + `blendMode()` — 直描きの合成

検証記録: https://github.com/shinyaoguri/metaphor-sketches/issues/19

## 意図的にしていないこと

- **`.alpha` の巡で絵が壊れるのを直していない。** 3D の層は `background()` を持たず
  下地が不透明な黒で固定されるので、前景に置くと下の版が丸ごと消える。
  これは作品が見つけたことなので、隠さずに出して欄外に理由を書く
- **`.multiply` の巡が黒く沈むのも直していない。** 透明な画素は premultiplied で
  rgb=0 なので、掛ければ 0 になる。合成の定義どおりの結果
