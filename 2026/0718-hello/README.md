```bash

```

## Run

```bash
metaphor watch --viewer   # live-reload window (recommended while iterating)
swift run                 # plain SwiftPM run, no metaphor-cli needed
```

The sketch entry point is `Sources/Sketch0718Hello/App.swift`.
