# PROJECT_BRIEF — 0816-triptych

## 一言

**三連祭壇画。** 3 枚のウィンドウに、1 つの連続した世界を分けて描く。

## 見せたいもの

横長の世界（幅 2880px）を、左翼 800 / 中央 1280 / 右翼 800 に切り分けて同時に描く。
中央がプライマリウィンドウ、左右の翼が `createWindow` で作るセカンダリウィンドウ。

- **行列** が世界を左から右へ延々と渡っていく。奥ほど遅く小さい（視差）
- **太陽** が 90 秒で世界を 1 周する。継ぎ目を跨ぐ大きな円
- **光の帯** が 6 秒で世界を走り抜ける（480px/s）
- **灯**（クリックで置く）に近づいた行列が暖色に灯る。灯は世界座標なのでどのパネルからでも見える
- 祭壇画の翼が開閉するように、**翼ウィンドウは 42 秒ごとに閉じて、また開く**（開 30 秒 / 閉 12 秒）

## 想定どおりと言える状態

**3 枚を左から順に並べたとき、1 枚の絵になっていること。**

- 行列も太陽も光の帯も、継ぎ目で途切れず渡る
- 下辺の**世界座標の目盛り**が 3 枚で連続している（0…800 / 800…2080 / 2080…2880）
- 翼が閉じている間も、中央だけで絵として閉じている
- 放っておいても開閉を繰り返し続け、落ちない・重くならない

## 主題としての狙い

「複数のウィンドウ」は、metaphor では **描画・入力・時計が丸ごと別系統になる**
（1 枚ごとに独立した `MetaphorRenderer` / `Canvas2D` / `InputManager` / レンダーループ）。

なので、**継ぎ目が絵の主題であると同時に検証の的**になる。3 枚が同じ世界の同じ時刻を
映していなければ、行列は継ぎ目で跳ぶ。光の帯は 480px/s で走るので、1 フレーム（16.7ms）の
時計のずれが約 8px の跳びとして目に見える。**作品がそのまま検流計になっている。**

下辺の目盛りと額の銘（そのパネルが映す世界 x の範囲）は、鑑賞のためであると同時に、
**ウィンドウの位置を指定する API が無いので人が並べるしかない**ことへの答えでもある。

## 描かないもの

- 3D は使わない（2D の連続性だけに絞る）
- 画像・モデル・音は読まない。すべて手続き生成
- ウィンドウを自動で並べようとしない（位置指定の口が無い。詳細は README）
