# 0815-lifegame Brief

Template: `2d`（3D 描画は自前で組んだ）

## Intent

- 暗い宇宙に浮かぶ立方体の培養槽。その中で細胞群が生まれ、群体になり、崩れていく。
  観測装置ごしに標本を眺めている、という体裁の SF。
- 最初に目を引くのは、ゆっくり自転する発光した群体。次に左上の計器（世代・個体数・入れ替わり）。
- 時間とともに群体の形が変わり続ける。停滞・絶滅したら自動で蒔き直し、放置しても絵が死なない。

## Constraints

- 解像度 / アスペクト: 1280×720
- 性能目標: 60fps（デバッグビルドで維持できること。`metaphor watch` はデバッグビルド）
- 入力: マウス移動で視点にオフセット（ドラッグ不要）、`SPACE` 一時停止 / `R` 蒔き直し / `N` 1 世代
- 必要アセット: なし（すべて手続き生成）

## Visual Direction

- パレット: 背景は深い藍（4, 7, 12）。生きた細胞は核に近いほどシアン、外縁ほど青紫、
  生まれた直後だけ白熱。減衰中の細胞は紫の残光で、二乗で急速に沈む。枠は淡いシアン。
- モーション: 群体の自転は毎秒 0.14rad。生死はステップ（既定 120ms）で離散的に決まるが、
  表示強度を実時間で補間しているので明滅は滑らか。
- モチーフ: 培養槽（ワイヤーフレームの立方体 + 上下面のグリッド）、観測 HUD、星空、Bloom。
- 奥行き: 視点から見た z で明度を落とすフォグを CPU 側で計算し、群体に厚みを出す。

## 仕組み（要点）

- ルールは 3D セルオートマトンの慣習表記 `生存 / 誕生 / 状態数 / 近傍(Moore)`。
  既定は **pyroclastic `4-7 / 6-8 / 10`**。他に amoeba / 445 / coral / architecture / crystal。
  ルールを切り替えると、そのルールが育ちやすい初期密度・初期領域へ自動で揃えて蒔き直す
  （445 と crystal は「ひと粒の種」から、coral と architecture は疎なスープから、
  amoeba は濃い塊から育つ。この初期条件を外すとほとんどのルールは数十世代で絶滅する）。
- **多状態**（states > 2）: 死んだ細胞は 1 段階ずつ減衰して消え、その間は生き返らない。
  この減衰段階が群体に軌跡と厚みを与えている（2 状態の 3D ライフはたいてい即絶滅か飽和になる）。
- 近傍数は 26 近傍を直接数えず、3×3×3 ブロック和が軸ごとに分離できることを使って
  X → Y → Z の 3 パスで求める（デバッグビルドで 100ms → 7ms）。
- 境界は既定でトーラス（`wrapEdges`）。切ると壁際が削れて群体が痩せる。
- 描画は `drawInstanced` の 1 draw call。`shellOnly` で群体の内側（26 近傍すべて生存）を省く。

## Iteration Notes

- Keep: 多状態の減衰、滑らかな明滅、トーラス境界、自動リシード、HUD の情報密度。
- Improve: ルールごとのプリセット（`gridSize` / `stepInterval` も含めて）を増やす余地。
  群体を切る断面図モードや、世代の履歴グラフも計器として面白い。
- Avoid: 白飛び（誕生フラッシュを強くしすぎない）、残光がマゼンタで画面を覆うこと。
